# 化合物解析 UI 规范（按效果图）

> 来源：`化合物插件功能及UI调整.md` 四张效果图（1218×760）  
> 对照基准色已从 PNG 采样；实现栈：Vue 3 + Element Plus。

## 0. 与当前实现的主要差距

| 项 | 效果图 | 当前实现 |
|----|--------|----------|
| 外壳 | 近全屏白底弹窗，外圈 `#f5f5f5`，无大圆角厚阴影 | 居中卡片 + 渐变背景 + 圆角阴影 |
| 标题栏 | 「化合物解析」+ 右上关闭 X + 底部分割线 | 仅标题，无关闭、无线 |
| 上传行 | 灰底「上传CDXML文件」按钮 + 文件名输入 + **描边设置按钮** | 文字标签 + 浏览 append + **蓝色 link** |
| 次按钮 | 浅蓝底蓝字 `#ebf2fe` | 默认灰边白底 |
| 进度 | 右对齐「AI 结构化 8/9 · ID」+ 细进度条 | 有，但文案/布局不完全一致 |
| Tab | 无数量角标 | `解析结果 (0)` |
| 底栏·结果态 | 左「运行日志」/ 右「查看完整解析表」浅蓝按钮 | 始终塞满导出+导入 |
| 底栏·结构态 | 左日志+三导出 / 右两导入 | 导入数据用了 primary 实心蓝 |
| 设置层 | 右侧浮层，**内含页签**切换匹配/AI | 两个独立 Drawer，无内页签 |
| 结构列 | 白底细边框图 + 下方 SMILES | 有，但边框/间距偏 Element 默认 |
| 结构化表 | 多级表头 + **Compound_ID 纵向合并** | 多级表头有，无 rowspan |

## 1. 画布与外壳

```
外页背景: #f5f5f5
弹窗面板: #ffffff
外边距: 约 8–12px（贴齐视口，非居中窄卡片）
圆角: 2–4px（接近直角，禁止大圆角卡片感）
阴影: 无或极弱 0 1px 4px rgba(0,0,0,.06)
弹窗宽度: calc(100vw - 24px)，高度: calc(100vh - 24px)
内部结构: Header | Body(工具区+Tabs+表) | Footer 纵向三区
```

### 1.1 Header（高 ~48px）

- 左：标题「化合物解析」，字号 16–18px，字重 600，色 `#303133`
- 右：关闭图标 `×`（`el-icon` Close），色 `#909399`，hover `#606266`
- 底：1px 实线 `#e4e7ed`

## 4. 工具区布局

### 4.1 文件行（单行 flex）

```
[上传CDXML文件(灰按钮)] [文件名只读输入 ........ flex:1] [结构匹配设置] [AI 解析设置]
```

- 「上传CDXML文件」：`el-button`，背景 `#f5f7fa`，边 `#dcdfe6`，点击触发 `<input type=file accept=.cdxml,.xml>`
- **不要**「浏览」append；文件名直接显示在中间 `el-input`（readonly）
- 「结构匹配设置」「AI 解析设置」：默认描边按钮（非 link、非 primary）
- 无文件时输入 placeholder：`请选择 .cdxml 文件`

### 4.2 操作行

```
左: [开始解析 primary] [文本解析 secondary] [自动执行 secondary]
右: 状态文案 + 进度条(宽 ~200–240px)
```

- 开始解析：实心 primary，白字
- 文本解析 / 自动执行：背景 `#ebf2fe`，文字/边框 `#409eff`（`type="primary" plain` + 微调）
- 状态文案格式：`AI 结构化 {done}/{total} · {compoundId}`；非 AI 时显示简短 status
- 进度条：`el-progress`，`stroke-width: 6–8`，无百分比文字（`text-inside=false` `:show-text=false`）
- 仅 AI 进行中或刚结束短暂显示进度条

### 4.3 提示行

固定文案（12px 灰）：

> 请先运行 \<结构解析\> 再进行 \<文本解析\>，点击 \<自动执行\> 将自动排除无法解析的结构和内容

---

## 5. Tabs

四个页签，**标签不含数量**：

1. 解析结果  
2. 未匹配结构  
3. 结构化数据表  
4. 解析失败文本  

- 组件：`el-tabs`，`type` 默认（下划线）
- 激活：文字 primary + 底指示条 2px
- 未激活：`#303133` / `#606266`
- Tabs 与表格之间无多余大空隙；表格占满剩余高度并可内部滚动

---

## 6. 表格规范

### 6.1 通用

- `el-table`：`border`，表头背景 `#f6f6f6`，字重 500
- 单元格垂直：**顶部对齐**（结构列、待解析文字多行）
- 行高随内容，结构列最小高度约 96px
- 空态：居中「暂无数据」

### 6.2 解析结果列

| 列 | 宽 | 内容 |
|----|----|------|
| Compound_ID | 120–140 | 文本 |
| 结构 | min 200 | 见下 |
| tPSA | 90 | 数值 |
| CLogP | 100 | 数值 |
| 待解析文字 | flex | 多行，保留换行 `white-space: pre-wrap` |

**结构单元格：**

```
┌──────────────┐
│  [结构 SVG]  │  ← 白底、1px #e4e7ed、圆角 2px、内边距 4px、居中
└──────────────┘
SMILES 文本（可折行，max-width 与图同宽）
```

### 6.3 未匹配结构

列：结构序号 | 结构（同上） | 中心 X | 中心 Y | 边界框

### 6.4 结构化数据表

- **两级表头**：一级为表名（IC50 / auc / Fu / solubility / mms / cyp_inhibition），二级为字段（去掉重复 Compound_ID）
- **Compound_ID 列**：相同 ID 连续行使用 `span-method` **纵向合并**
- 其余字段：按「第 N 条记录横向对齐」填入（已有 merge 逻辑）
- 表头文字居中；数值列居中；过长 `show-overflow-tooltip`

### 6.5 解析失败文本

列：Compound_ID | 失败原因 | 原文

---

## 7. 底栏（Footer）

高 ~52px，顶部分割线 `#e4e7ed`，左右分布。

### 7.1 默认态（解析结果 / 未匹配 / 失败）

- 左：`运行日志`（默认描边）
- 右：`查看完整解析表`（浅蓝次按钮，点击切到「结构化数据表」；若无数据则提示）

### 7.2 结构化数据表态

- 左：`运行日志` `导出结构解析结果` `导出审查清单` `导出结构化数据表`（全部默认描边）
- 右：`导入化合物结构`（描边）`导入化合物数据`（描边或浅蓝次按钮，**不用实心 primary**）

---

## 8. 右侧设置浮层

- 组件：`el-drawer`，`direction=rtl`，宽度 420–480px
- **单一 Drawer**，内部 `el-tabs`：
  1. 结构匹配设置  
  2. 跨行匹配设置（占位：说明「暂与 Y 向下匹配合并」或预留空表单，避免效果图页签缺失）  
  3. AI 解析设置  
- 打开方式：点顶栏对应按钮 → 打开 Drawer 并切到对应页签
- 遮罩半透明；点遮罩可关

### 8.1 结构匹配设置

- 结构 X 扩展（坐标）：左侧 / 右侧 `el-input-number`，默认可 50 / 50（效果图），代码默认仍可读 localStorage，无则 0  
- 结构 Y 扩展（坐标）：向下，效果图 200；持久化 key 同现有 `match_y_down`  
- 底右：`保存配置`（描边/次按钮）

### 8.2 AI 解析设置

- 顶右角元信息：`并发 {n}`；AI 运行中追加 `AI 结构化: a/b`
- 字段：API Base URL、API Key（password）、Model、并发、System Prompt（大 textarea ≥10 行）、User Prompt 模板
- 底：`保存配置` `测试连接`（均为描边）

---

## 9. 交互与状态

| 动作 | 行为 |
|------|------|
| 上传按钮 / 点击文件名框 | 打开文件选择 |
| 开始解析 | 调 `/api/parse`，填解析结果 Tab |
| 文本解析 | 需已有解析结果；SSE 进度 |
| 自动执行 | 解析 → 过滤无 SMILES/无 text → 文本解析 |
| 运行日志 | 右侧或底部 Drawer 展示日志 |
| 查看完整解析表 | `activeTab = structured` |

## 10. 响应式

- 最小宽度 960px；小于此出现横向滚动，不折叠为移动布局
- Drawer 在窄屏仍为 100% 宽上限 480px
