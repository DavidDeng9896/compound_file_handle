
# CDXML 化合物数据解析工具 - 项目总结

## 项目概述

本项目提供从 ChemDraw 导出的 CDXML 中提取化合物结构（SMILES）及页面上 HW、tPSA、CLogP、其他说明文字的匹配能力，并导出 CSV。包含 **Python 核心**（`cdxml/parser.py`）、**Electron 桌面壳**（解析参数可在界面填写）、以及 **PySide6 界面**（`cdxml/gui.py`）等入口。

## 最终成果（示例数据）

在示例 CDXML 上曾得到类似规模的结果（随文件与匹配参数而变）：

- 约 **259** 个化合物结构、**257** 个 HW 编号、**248** 条左右完整匹配行等（历史统计，仅供参考）。

### 主要输出

- `cdxml/parser.py` — 主解析与匹配逻辑（推荐）
- `compounds_output_final.csv` / 用户指定路径 — 主结果 CSV
- Electron 打包：`electron/` 下 `npm run dist:unpacked` → `electron/dist-installer/win-unpacked`

## 核心算法

### 1. 元素分类

从 `<page>` 的直接子节点中收集：

1. **fragment**：有原子与键的分子结构，可转 SMILES  
2. **以 HW 开头的 t 节点**：化合物编号  
3. **含 tPSA / CLogP 的 t 节点**：属性行（同时用于 tPSA 与 CLogP 解析）  
4. **其他 t 节点**：IC50、AUC 等说明文字  

无 BoundingBox 或全零时，可用 `p` 与 fragment 子树内 `<n>` 的 `p` 回推几何（见代码内 `resolve_bbox_fragment` / `resolve_bbox_t`）。

### 2. X 轴重叠（结构左右扩展）

对 **结构** 的包围框在 X 方向按 **CDXML 坐标的绝对长度** 左右扩展后，再与 **文字框** 判断区间是否相交：

```python
def has_x_overlap(bbox1, bbox2, x_extend_left=0.0, x_extend_right=0.0):
    el = max(0.0, float(x_extend_left))
    er = max(0.0, float(x_extend_right))
    x1 = bbox1["x1"] - el
    x2 = bbox1["x2"] + er
    return x1 <= bbox2["x2"] and bbox2["x1"] <= x2
```

- **左扩展**：结构左边界向左延伸 `x_extend_left`  
- **右扩展**：结构右边界向右延伸 `x_extend_right`  
- 二者默认 **0 / 0** 时，仅按原始结构宽度与文字做 X 重叠判断  

### 3. 「结构 Y 向下匹配数值」`match_y_down`

单一阈值（默认 **130**，CDXML 坐标单位），用于下列距离是否 **小于** 该值：

| 步骤 | 距离定义 |
|------|----------|
| HW ↔ 结构 | `\|HW.center_y − struct.center_y\|` |
| tPSA / CLogP ↔ 结构 | 结构中心与文字中心 **欧氏距离** |
| 其他文字 ↔ 结构 | 结构 **底边中点** 与文字 **顶边中点** 的欧氏距离（文字多在结构下方） |

在已通过 X 重叠的候选中，取距离最小且未占用的匹配。

### 4. SMILES

使用 RDKit 将 fragment 转为 SMILES（含嵌套 fragment 等逻辑，见 `parse_fragment_to_smiles`）。

## 参数配置（与代码一致）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `match_x_extend_left` | 0 | 结构框左侧向左扩展长度（坐标单位） |
| `match_x_extend_right` | 0 | 结构框右侧向右扩展长度（坐标单位） |
| `match_y_down` | 130 | 上述 Y/距离阈值上限 |

Python 调用示例：

```python
main(
    "input.cdxml",
    "out.csv",
    log=print,
    match_x_extend_left=10.0,
    match_x_extend_right=20.0,
    match_y_down=130.0,
)
```

### Electron 与命令行桥接

- 界面：**结构 X 扩展（左 / 右）**、**结构 Y 向下匹配数值**；数值会写入 `localStorage`，解析成功后再保存一次。  
- 子进程：`python -m cdxml.bridge`  

```text
python -m cdxml.bridge <cdxml> <out.csv> [左扩展] [右扩展] [Y向下匹配]
```

打包后由 `resources/bridge/cdxml-bridge.exe` 接收相同顺序的 5 个参数（前两为路径，后三为浮点数）。**第二项为 `__NO_CSV__` 时不写 CSV**，仅返回 JSON；桌面端在解析成功后通过「导出主结果 CSV」再保存文件。

**Electron 界面**：点击「开始解析」时不写主结果 CSV；解析成功后通过「**导出主结果 CSV…**」再保存（与 Python `csv.writer` 列一致）。桥接第二参数为占位符 **`__NO_CSV__`** 时，`main()` 不写入文件，仅返回 JSON。

## 技术栈

- Python 3.x、`xml.etree.ElementTree`、CSV  
- RDKit（SMILES）  
- Electron + SmilesDrawer（桌面 UI 与结构式渲染）  

## 文件说明（节选）

| 文件 | 作用 |
|------|------|
| `cdxml/parser.py` | 解析、匹配；`output_path` 为空则跳过写 CSV |
| `cdxml/bridge.py` | 供 Electron 调用的 JSON 单行输出桥接 |
| `electron/main.js` / `renderer.js` / `index.html` | 桌面 UI |
| `packaging/cdxml-bridge.spec` | PyInstaller 打包桥接 exe |
| `scripts/export_review.py` | 导出未匹配 HW/结构等审查清单 |

## 使用方法

```bash
# 命令行（仓库根目录）
python -m cdxml "samples/cdxml/EO018 compounds list 20240809.cdxml" -o compounds_output.csv

# 或使用桥接（可带匹配参数）
python -m cdxml.bridge input.cdxml out.csv 0 0 130

# 仅解析、不写 CSV（与 Electron「开始解析」一致）
python -m cdxml.bridge input.cdxml __NO_CSV__ 0 0 130
```

Electron 开发：`cd electron && npm start`；打包免安装目录：`npm run dist:unpacked`。解析完成后点击 **导出主结果 CSV** 写入与命令行相同的主表。

## 输出 CSV 列

| 列名 | 说明 |
|------|------|
| Compound_ID | HW 编号等 |
| structure | SMILES |
| tPSA | 解析值 |
| CLogP | 解析值 |
| text | 其他匹配到的文字 |

## 项目亮点

1. 空间匹配：X 方向可分别控制左右扩展，Y/距离统一用「向下匹配数值」阈值约束。  
2. 无 BoundingBox 的 ACD 类导出：基于 `p` 与 fragment 内原子点聚合几何。  
3. Electron 可调参并持久化；桥接 exe 便于离线分发。

功能持续迭代中；匹配条数随 CDXML 版式与上述三项参数变化，需在具体文件上试算。
