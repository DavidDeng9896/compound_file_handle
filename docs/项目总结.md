# CDXML 化合物数据解析工具 - 项目总结

## 项目概述

本项目提供从 ChemDraw 导出的 CDXML 中提取化合物结构（SMILES）及页面上 HW、tPSA、CLogP、其他说明文字的匹配能力，并导出 CSV。采用 **前后端分离**：Python 全部在 `backend/`（`cdxml_parser` + FastAPI），前端在 `frontend/`（Vue3 + Element Plus）。

**已实现功能一览**见 [功能说明.md](./功能说明.md)。

## 最终成果（示例数据）

在示例 CDXML 上曾得到类似规模的结果（随文件与匹配参数而变）：

- 约 **259** 个化合物结构、**257** 个 HW 编号、**248** 条左右完整匹配行等（历史统计，仅供参考）。

### 主要输出

- `backend/cdxml_parser/parser.py` — 主解析与匹配逻辑
- 用户指定路径 / Web 导出 — 主结果 CSV
- Web UI：`frontend/` 经 `backend/app` API 调用解析与 AI 结构化

## 核心算法

### 1. 元素分类

从 `<page>` 的直接子节点中收集：

1. **fragment**：有原子与键的分子结构，可转 SMILES  
2. **以 HW 开头的 t 节点**：化合物编号  
3. **含 tPSA / CLogP 的 t 节点**：属性行（同时用于 tPSA 与 CLogP 解析）  
4. **其他 t 节点**：IC50、AUC 等说明文字  

无 BoundingBox 或全零时，可用 `p` 与 fragment 子树内 `<n>` 的 `p` 回推几何（见代码内 `resolve_bbox_fragment` / `resolve_bbox_t`）。

### 2. X 轴重叠（结构左右扩展）

对 **结构** 的包围框在 X 方向按 **CDXML 坐标的绝对长度** 左右扩展后，再与 **文字框** 判断区间是否相交：

```python
def has_x_overlap(bbox1, bbox2, x_extend_left=0.0, x_extend_right=0.0):
    el = max(0.0, float(x_extend_left))
    er = max(0.0, float(x_extend_right))
    x1 = bbox1["x1"] - el
    x2 = bbox1["x2"] + er
    return x1 <= bbox2["x2"] and bbox2["x1"] <= x2
```

- **左扩展**：结构左边界向左延伸 `x_extend_left`  
- **右扩展**：结构右边界向右延伸 `x_extend_right`  
- 二者默认 **0 / 0** 时，仅按原始结构宽度与文字做 X 重叠判断  

### 3. 「结构 Y 向下匹配数值」`match_y_down`

阈值（默认 **300**，CDXML 坐标单位）用途因匹配类型而异：

| 步骤 | 规则 |
|------|------|
| HW ↔ 结构 | `\|HW.center_y − struct.center_y\| < match_y_down`；写入编号时去掉**末尾**一对圆括号（如 `HW1800023(VET,102354)` → `HW1800023`） |
| tPSA / CLogP ↔ 结构 | 结构中心与文字中心 **欧氏距离** `< match_y_down` |
| 其他文字 ↔ 结构 | 见下节「Y 区间归属」 |

HW / 属性：在已通过 X 重叠的候选中，取距离最小且未占用的匹配。

### 3.1 其他文字 Y 区间归属

1. **下一结构**：与当前结构 X 重叠、且 `center_y` 更大者中最近的一个；若无，则仅用 `match_y_down`。
2. **Y 上界**：`min(结构底边 + match_y_down, 下一结构顶边)`（无下一结构时为 `底边 + match_y_down`）。
3. **可归属**：X 重叠，且文字顶边 `y1` 落在 `[结构底边, Y 上界]`。
4. **独占**：每段其他文字只归一个结构；多候选取「结构底边中点 ↔ 文字顶边中点」距离最近者；再按该距离升序空格拼接为 `text`。

因此可将 `match_y_down` 调大以覆盖较长文字块，同时由下一结构顶边防止跨行误配。

### 4. SMILES

使用 RDKit 将 fragment 转为 SMILES（含嵌套 fragment 等逻辑，见 `parse_fragment_to_smiles`）。

## 参数配置（与代码一致）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `match_x_extend_left` | 0 | 结构框左侧向左扩展长度（坐标单位） |
| `match_x_extend_right` | 0 | 结构框右侧向右扩展长度（坐标单位） |
| `match_y_down` | 300 | 上述 Y/距离阈值上限 |

Python 调用示例：

```python
from cdxml_parser.parser import main

main(
    "input.cdxml",
    "out.csv",
    log=print,
    match_x_extend_left=10.0,
    match_x_extend_right=20.0,
    match_y_down=300.0,
)
```

Web UI 中可在设置面板调整上述三项；命令行见 `python -m cdxml_parser --help`。

## 技术栈

- Python 3.x、`xml.etree.ElementTree`、CSV、RDKit（SMILES）
- FastAPI（`backend/app`）+ Vue3 / Element Plus / Vite（`frontend/`）
- 可选：OpenAI 兼容 API（`backend/cdxml_parser/text_ai/`）做 text 结构化

## 文件说明（节选）

| 文件 | 作用 |
|------|------|
| `backend/cdxml_parser/parser.py` | 解析、匹配；`output_path` 为空则跳过写 CSV |
| `backend/cdxml_parser/text_ai/` | AI 结构化 schema、批量、导出、连表合并 |
| `backend/app/main.py` | Web API |
| `frontend/src/App.vue` | 前端主界面 |
| `scripts/dev.sh` | 本地一键启动 API + Vite |
| `backend/tests/` | pytest 单元测试 |

## 使用方法

```bash
# 命令行（在 backend/ 下）
cd backend
PYTHONPATH=. python -m cdxml_parser "../samples/cdxml/EO018 compounds list 20240809.cdxml" -o compounds_output.csv

# Web UI
pip install -r requirements.txt
cd frontend && npm install && cd ..
./scripts/dev.sh
# 浏览器打开 http://127.0.0.1:5173
```

## 输出 CSV 列

| 列名 | 说明 |
|------|------|
| Compound_ID | HW 编号等 |
| structure | SMILES |
| tPSA | 解析值 |
| CLogP | 解析值 |
| text | 其他匹配到的文字 |

## 项目亮点

1. 空间匹配：X 方向可分别控制左右扩展，Y/距离统一用「向下匹配数值」阈值约束。  
2. 无 BoundingBox 的 ACD 类导出：基于 `p` 与 fragment 内原子点聚合几何。  
3. Web UI 可调参、预览结构、导出结果，并对 text 做 AI 结构化拆表。
